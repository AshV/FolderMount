Introduction

Welcome to the FolderMount for Windows User Guide. FolderMount is a lightweight utility that maps local folders to virtual drive letters (like P: or Z:) using the native Windows SUBST command.

Key Benefit: By mapping a deeply nested folder to a drive letter, you bypass the notorious 260-character MAX_PATH limit in Windows, fixing build errors in Node.js, Python, and Unity.

Getting Started

Installation

FolderMount is available exclusively on the Microsoft Store for Windows 10 and 11. It installs locally to your user profile and requires zero administrator privileges.

  1. Open the Microsoft Store app on Windows.
  2. Search for "FolderMount" or click the direct link.
  3. Click Install.
  4. Launch FolderMount from your Start Menu.

Creating Mappings

Adding a new virtual drive is incredibly simple:

  1. Click the + Add Mapping button on the main toolbar.
  2. A new row will appear. Select your desired Drive Letter from the dropdown. Only available letters are shown.
  3. Click the Browse button next to the folder path input, or manually paste the path (e.g., C:\Projects\MyApp).
  4. Optionally, add a Friendly Label (e.g., "Web App Codebase").
  5. Check the Mount automatically on Startup box if you want this drive to persist across reboots.
  6. Click the Mount icon (Play button) or Mount All on the toolbar to activate the drive.

Your new drive will instantly appear in Windows File Explorer!

System Tray Integration

FolderMount is designed to stay out of your way. When you close the main window, the app continues running silently in the system tray.

  • Left-Click: Double-click the tray icon to restore the main window.
  • Right-Click: Access quick actions like Mount All, Unmount All, or exit the application completely.

Settings & XML Export

Click the Settings button (Gear icon) to manage application behavior:

  • Run at Windows Startup: Ensures your drives are silently mounted the moment you log in.
  • Theme Preferences: Switch between Light, Dark, or System themes.
  • Import / Export: FolderMount saves mappings to an XML file. You can export this file to share your workspace setup with your team, and easily import it on another computer.

Troubleshooting

Drive letter is not available

If a drive letter is missing from the dropdown, it means Windows has already assigned it to a physical disk, optical drive, or network share.

Drive unmounts when I restart

Check Startup Settings: Ensure "Run FolderMount on Windows Startup" is enabled in the Settings window. FolderMount must run silently in the background at login to restore the mappings.

Administrator / UAC

FolderMount does not need administrator rights. If you encounter permissions errors, ensure your Windows User Account has read/write access to the target folder you are trying to mount.
