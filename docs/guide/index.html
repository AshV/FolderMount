Introduction

Welcome to the FolderMount for Windows User Guide. FolderMount is a lightweight utility that maps local folders to virtual drive letters (like P: or Z:) using the native Windows SUBST command.

Key Benefit: By mapping a deeply nested folder to a drive letter, you bypass the notorious 260-character MAX_PATH limit in Windows, fixing build errors in Node.js, Python, and Unity.

Getting Started

Installation

FolderMount is available exclusively on the Microsoft Store for Windows 10 and 11. It installs locally to your user profile and requires zero administrator privileges.

  1. Open the Microsoft Store app on Windows.
  2. Search for "FolderMount" or click the direct link.
  3. Click Install.
  4. Launch FolderMount from your Start Menu.

Creating Mappings

Adding a new virtual drive from within the application is simple:

  1. Click the + Add Mapping button on the main toolbar.
  2. A new row or dialog will appear. Select your desired Drive Letter from the dropdown. Only available letters are shown.
  3. Click the Browse button next to the folder path input, or manually paste the path (e.g., C:\Projects\MyApp).
  4. Optionally, add a Friendly Label (e.g., "Web App Codebase").
  5. Check the Mount automatically on Startup box if you want this drive to persist across reboots.
  6. Click the Mount icon (Play button) or Mount All on the toolbar to activate the drive.

Your new drive will instantly appear in Windows File Explorer!

Faster Alternative: You can also mount any folder in seconds without opening the main window first by right-clicking it directly in Windows Explorer. See Mount from Context Menu below.

Mounting from Windows Explorer Context Menu

For the quickest possible workflow, FolderMount integrates with the Windows File Explorer right-click context menu. You can turn any directory into a dedicated virtual drive in just two clicks.

Instant Mount Workflow: Right-click folder → click "Mount as Drive (FolderMount)" → click "Add Mapping".

How to Use

  1. Open File Explorer and find the folder you want to mount as a drive.
  2. Right-click the folder:
    • Windows 10: Click Mount as Drive (FolderMount) directly from the context menu.
    • Windows 11: Press Shift + Right Click on the folder, or right-click and select Show more options (Shift + F10), then click Mount as Drive (FolderMount).
  3. The dedicated Mount as Drive (FolderMount) dialog appears immediately:
    • Folder Path: Automatically pre-filled with the directory you clicked.
    • Friendly Label: Automatically generated from the folder name (e.g. MyProject).
    • Drive Letter: Automatically selects the first available drive letter on your system, avoiding any conflicts with existing physical disks or network drives.
    • Mount automatically on Startup: Enabled by default to ensure the drive persists across logins.
  4. Click Add Mapping to mount the drive instantly via native Windows SUBST.
  5. A theme-matched confirmation dialog will prompt:
    "Drive [X:] has been mounted successfully. Would you like to open it in File Explorer?"
    Click Open Drive to open your new virtual drive immediately in File Explorer, or OK to close.

Focused, Distraction-Free Experience

Triggering FolderMount from the context menu brings up only the lightweight Mount as Drive popup rather than the full application window. If FolderMount is already running in your system tray, it communicates silently in the background so no duplicate processes or windows clutter your workspace.

System Tray Integration

FolderMount is designed to stay out of your way. When you close the main window, the app continues running silently in the system tray.

  • Left-Click: Double-click the tray icon to restore the main window.
  • Right-Click: Access quick actions like Mount All, Unmount All, or exit the application completely.

Settings & XML Export

Click the Settings button (Gear icon) on the main toolbar to manage system integration and preferences:

  • Folder Context Menu (Mount as Drive): Toggle the right-click Windows Explorer context menu on or off. Requires zero administrator privileges.
  • Run at Windows Startup: Ensures your drives are silently re-mounted the moment you log in to Windows.
  • Theme Preferences: Switch between Light, Dark, or System themes. All dialogs, confirmation prompts, and buttons automatically adapt to your theme.
  • Import / Export: FolderMount saves mappings to an XML file. You can export this file to share your workspace setup with your team, and easily import it on another computer.

Troubleshooting

Drive letter is not available

If a drive letter is missing from the dropdown, it means Windows has already assigned it to a physical disk, optical drive, or network share.

Drive unmounts when I restart

Check Startup Settings: Ensure "Run FolderMount on Windows Startup" is enabled in the Settings window. FolderMount must run silently in the background at login to restore the mappings.

I don't see "Mount as Drive" in Windows 11 right-click menu

Windows 11 defaults to a compact context menu. To access FolderMount:

  • Hold Shift while right-clicking any folder to jump directly to the full classic menu.
  • Or click Show more options at the bottom of the right-click menu.
  • Verify that Folder Context Menu is enabled in FolderMount Settings (Gear icon → System Integration).

Administrator / UAC

FolderMount does not need administrator rights. If you encounter permissions errors, ensure your Windows User Account has read/write access to the target folder you are trying to mount.
