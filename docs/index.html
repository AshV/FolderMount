What is FolderMount?

FolderMount is a lightning-fast, native Windows utility that allows you to map deeply nested or frequently used directories to a dedicated virtual drive letter (e.g., P:\). Unlike creating shortcuts, these mapped drives act exactly like real physical drives in Explorer and across all applications.

Why use it? It leverages the native Windows DefineDosDevice API, which means there is zero background processing overhead after a drive is mounted.

Getting Started

To begin using FolderMount:

  1. Download the latest release and run FolderMount.exe.
  2. The main dashboard will open, displaying your current drive mappings.
  3. If it's your first time, the list will be empty. Click "Add Mapping" to create your first virtual drive.

Creating a Mapping

Follow these steps to map a folder:

  1. Click the Add Mapping button in the top right of the dashboard.
  2. Drive Letter: Select an available drive letter from the dropdown (e.g., W: for Work).
  3. Folder Path: Browse and select the target directory you want to map.
  4. Label (Optional): Give the drive a custom name. This will appear in Windows Explorer.
  5. Mount on Startup: Check this box if you want this drive to automatically mount when you log in.
  6. Click Save. The drive will immediately appear in your "This PC" view.

System Tray & Background Execution

FolderMount is designed to stay out of your way. When you close the main window, the application continues running in the background.

  • Look for the FolderMount icon in your system tray (bottom-right corner).
  • Right-click the icon to quickly Mount All, Unmount All, or access Settings without opening the full UI.
  • Left-click the icon to bring up the main dashboard.
Note: To fully exit the application, right-click the tray icon and select Exit.

Themes & Settings

FolderMount features a modern aesthetic tailored to your preferences.

  • System Default: Matches your Windows 10/11 color mode automatically.
  • Dark Mode: A sleek, eye-friendly dark theme.
  • Light Mode: A clean and bright interface.

You can also access the Quick Import/Export feature in the Settings menu to backup your mappings or transfer them to another PC.

Troubleshooting

Drive letter says "Already in Use"

This means Windows, a network drive, or a USB stick is currently occupying that letter. Please select a different drive letter or eject the conflicting device.

Drive label doesn't update immediately

Sometimes Windows Explorer takes a moment to process the Shell Notification. Press F5 in your Explorer window, or try unmounting and remounting the drive.
